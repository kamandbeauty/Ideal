# intake/style-v3 — پوشه ورودی سبک جدید

اینجا جای دو چیز است:

```
intake/style-v3/
├── vo/          ← فایل صوتی نریشن (mp3 / wav / m4a / ogg)
└── reference/   ← ویدئو نمونه‌ای که انیمیشن باید شبیه آن باشد (mp4 / mov / webm)
```

می‌توانید فایل‌ها را مستقیم داخل همین پوشه هم بریزید؛ فقط بگویید کدام نریشن است و کدام نمونه.

## نریشن (`vo/`)

- هرچه دارید همان‌طور بریزید: یک فایل کامل، یا چند فایل جدا (مثلاً `c01.mp3`, `c02.mp3`).
- اگر متن نریشن را هم می‌خواهید دقیق بچینم، یک `vo/script.txt` کنارش بگذارید (هر خط = یک جمله/سکشن).
- فرمت‌های قابل خواندن: mp3, wav, m4a, aac, ogg, flac.
- اگر فایل کامل است، سکوت‌ها را خودم با `silencedetect` درمی‌آورم و کات‌ها را روی همان‌ها می‌گذارم — نیازی به برش دستی نیست.

## نمونه ویدئو (`reference/`)

- همان ویدئویی که «حس و انیمیشنش» را می‌خواهید. کیفیت مهم نیست، فقط سبک حرکت و تایپوگرافی معلوم باشد.
- اگر ویدئو خیلی سنگین است (بیش از ~۵۰ مگابایت) اول یک نسخه سبک‌تر یا فقط لینک/نام آن را بدهید؛ لازم نیست کل فایل در گیت بماند.
- اگر صحنه‌های شاخصی دارد (مثلاً ثانیه ۱۲ و ۳۴)، در یک `reference/notes.txt` بنویسید «این را می‌خواهم» / «این را نه».

## بعد از ریختن فایل‌ها

۱. من فریم‌های کلیدی نمونه را درمی‌آورم و سبک را به زبان فنی توصیف می‌کنم (نوع حرکت دوربین، رفتار تایپ، ریتم کات، پالت، بافت).
۲. با هم روی یک «استایل‌شیت» کوتاه (۱۰–۱۵ فریم تست) توافق می‌کنیم.
۳. بعد کل ویدئو با آن سبک ساخته می‌شود.

> نکته: پوشه `motion/odd-file/` دست‌نخورده می‌ماند تا اگر خواستید به سبک قبلی برگردید، همه‌چیز سر جایش باشد.
