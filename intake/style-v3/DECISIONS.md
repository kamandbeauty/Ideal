# دستور کار — سبک جدید (style-v3)

تصمیم‌های قطعی‌شده (۲ نوامبر ۲۰۲۶):

| موضوع | تصمیم |
| --- | --- |
| خروجی | **دو فایل جدا**: یک MP4 فارسی، یک MP4 انگلیسی — هر دو از یک تصویر/همان تایم‌لاین |
| ویس فارسی | **کاربر خودش ضبط و آپلود می‌کند** (نه TTS) |
| ویس انگلیسی | نسخه انگلیسی همان ویدئو (ویس اور روی همان تصویر) |
| زیرنویس | هر نسخه زیرنویس زبان خودش: `fa.srt` برای فارسی، `en.srt` برای انگلیسی |
| سبک بصری | از روی نمونهٔ ویدئو در `reference/` استخراج می‌شود |
| پوشهٔ قدیمی | `motion/odd-file/` دست‌نخورده می‌ماند |

## ورودی‌های مورد انتظار

```
intake/style-v3/vo/          ← نریشن فارسی (mp3/wav/m4a/ogg/flac)
intake/style-v3/reference/   ← ویدئو نمونه سبک (mp4/mov/webm)
```

## معماری برنامه‌ریزی‌شده

یک تایم‌لاین و یک مجموعه صحنه، دو میکس صدا:

1. `vo/` فارسی را می‌خوانم، سکوت‌ها را با `silencedetect` درمی‌آورم، `timeline.fa.js` می‌سازم.
2. نسخه انگلیسی هم همان متن/همان ساختار صحنه است، ولی زمان‌بندی از صداگذاری انگلیسی خودش می‌آید (`timeline.en.js`)؛ اگر طول‌ها تفاوت داشت، موتور از تایم‌لاین خودِ هر زبان رندر می‌کند تا هیچ زبانی فشرده یا کشیده نشود.
3. هر نسخه: `exports/style-v3-fa-1080p.mp4` و `exports/style-v3-en-1080p.mp4`.
