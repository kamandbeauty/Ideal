# قابک | Qabak Comics — اپلیکیشن کامیک‌خوان اندروید

اپلیکیشن نیتیو اندروید برای مطالعه و مدیریت کتابخانه کمیک، مانگا و وب‌تون — ساخته‌شده با **Kotlin**، **Jetpack Compose** و **Material 3**.

A native bilingual (Persian RTL & English LTR) Android comic book, manga, and webtoon reader built with **Kotlin 2.0**, **Jetpack Compose**, **Room**, and **Material 3**.

## قابلیت‌های کلیدی (Key Features)

- **دوزبانه واقعی (فارسی و انگلیسی):** تغییر آنی زبان با یک لمس، چیدمان راست‌به‌چپ (RTL) و چپ‌به‌راست (LTR)، فونت فارسی توکار **وزیرمتن (Vazirmatn)** و اعداد فارسی.
- **۳ کامیک تصویرسازی‌شده آماده داخل اپ:**
  1. *نگهبان البرز: بیداری سیمرغ* (`Guardian of Alborz`) — فانتزی اساطیری چندپنلی
  2. *نئون تهران ۲۰۹۹: فرکانس گمشده* (`Neon Tehran 2099`) — سایبرپانک نوآر
  3. *سرود سپیده‌دم* (`Song of Dawn`) — اپیزود وب‌تون عمودی
  - همراه با حباب‌های گفتگوی دوزبانه قابل تغییر بین **فارسی**، **انگلیسی** و **فقط تصویر (Art Only)**.
- **پشتیبانی از فایل‌های شخصی گوشی:**
  - آرشیوهای **CBZ / ZIP** (با مرتب‌سازی هوشمند شماره‌گذاری صفحات و خواندن خودکار متادیتای `ComicInfo.xml`)
  - آرشیوهای **CBR / RAR**
  - کتاب‌ها و کمیک‌های **PDF** (رندر سخت‌افزاری با `PdfRenderer`)
  - وارد کردن **پوشه تصاویر** یا ساخت یک جلد کمیک از **چند عکس گالری**
  - باز کردن مستقیم فایل‌ها از فایل‌منیجر و پیام‌رسان‌ها (`Open with Qabak`) و خروجی اشتراک‌گذاری با فرمت استاندارد `.cbz`
- **۴ حالت مطالعه حرفه‌ای:**
  1. ورق‌زدنی راست‌به‌چپ (فارسی / مانگا)
  2. ورق‌زدنی چپ‌به‌راست (کمیک غربی)
  3. اسکرول عمودی پیوسته (وب‌تون)
  4. **نمای هوشمند قاب‌به‌قاب (Guided Panel View)** با تشخیص خودکار قاب‌های صفحه
- **ابزارهای خواننده:** زوم دو انگشتی و دوبار لمس، نوار مرور سریع صفحات، فیلترهای رنگ (اصلی، سپیا شب، سیاه‌وسفید مانگا، جوهر پررنگ)، تنظیم روشنایی و فیلتر نور گرم محافظ چشم، ورق زدن با دکمه‌های صدا، روشن ماندن صفحه، و ۳ پوسته ظاهری (تاریک جوهری، روشن کاغذی، مشکی OLED).
- **قفسه هوشمند و نشانک‌ها:** کارت ادامه مطالعه، ذخیره خودکار آخرین صفحه، فیلتر، جستجو، مرتب‌سازی، علاقه‌مندی‌ها، کارنامه آمار مطالعه و نشانک‌گذاری صفحات همراه با یادداشت شخصی.

## ساخت از روی سورس (Build from Source)

پروژه را در **Android Studio Ladybug+** باز کنید یا با خط فرمان بسازید:

```bash
cd comic_app
gradle testDebugUnitTest      # اجرای تست‌های واحد و رابط کاربری
gradle assembleDebug          # ساخت نسخه Debug
gradle assembleRelease        # ساخت نسخه Release بهینه‌شده با R8
```
