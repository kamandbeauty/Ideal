## 15. Fact check

| Claim in the film | Status | Source |
| --- | --- | --- |
| Memories are reconstructed, not replayed | Established | Bartlett (1932); Loftus, Miller & Burns (1978), *JEP:HLM* 4:19–31 |
| Recalling can return a memory to an editable state (“reconsolidation”) | Established in animals; active and mixed in humans | Nader, Schafe & LeDoux (2000), *Nature* 406:722–726 |
| Details change over time | Established | Loftus misinformation-effect studies; DRM false-memory paradigm |
| The mind can fill gaps with events that never happened | Established | Loftus & Pickrell (1995), *Psychiatric Annals* 25:720–725 (“lost in the mall”) |
| Strong memory ≠ accurate memory | Established | Talarico & Rubin (2003), *Memory & Cognition* 31:844–856 — flashbulb memories lose accuracy while confidence stays high |

**Nuance kept out of the 28 seconds:** reconsolidation does not happen on every recall — it depends on conditions such as prediction error — and human evidence is less settled than the animal work. The line “Neuroscientists call it reconsolidation” is accurate; the film never claims every memory is rewritten every time.
