# ۱۵۱۸ — رقص استراسبورگ

ویدئوی عمودی ۹:۱۶ · فارسی · سبک «کتاب مصور» با عروسک اسکلت‌بندی‌شدهٔ دوبعدی.

| مورد | مقدار |
| --- | --- |
| ابعاد | ۱۰۸۰×۱۹۲۰ (۹:۱۶) |
| نرخ فریم | ۳۰ fps |
| مدت | ۱۵۳٫۱ ثانیه (نریشن ۱۵۲ ثانیه + ۱٫۱ ثانیه نگه‌داشتن فریم آخر) |
| صحنه | ۲۰ صحنه — یک صحنه برای هر جملهٔ نریشن |
| زیرنویس | ۵۲ کیوی فارسی، داخل تصویر پخته‌شده + `subtitles/fa.srt` |
| صدا | `audio/mix.wav` — نریشن + درون (درون پایین، ضربان قلب هر ۱٫۴۲ ثانیه، روم‌تون) |
| بلندی صدا | ‎−۱۳٫۵ LUFS، پیک واقعی ‎−۰٫۸ dBTP |

## ساختار پوشه

```
content/script.js      متن بیست جمله (یک جمله = یک صحنه)
content/timeline.js    تولیدشده: زمان صحنه‌ها + کیوهای زیرنویس
content/scenes.js      پلیت، بازیگرها، جمعیت و حرکت دوربین هر صحنه
engine/rig.js          اسکلت عروسک: ۸ مفصل + حالت‌های dance/still/collapse/play/wave
index.html             موتور صحنه (SVG + تایپوگرافی + پخش فریم‌به‌فریم)
assets/plates/sNN.jpg  بیست پس‌زمینهٔ نقاشی‌شده (بدون شخصیت، بدون متن)
audio/build.mjs        میکس نریشن + موسیقی
tools/timeline.mjs     ساخت تایم‌لاین از روی WAV نریشن
render.mjs             رندر فریم‌به‌فریم + انکود
```

## چطور دوباره ساخته می‌شود

```bash
node tools/timeline.mjs        # تایم‌لاین و SRT از روی ویس
node audio/build.mjs           # mix.wav
node render.mjs --stills 8     # بازبینی چند فریم
node render.mjs --fast         # فیلم کامل
node render.mjs --fast --from 0 --to 57   # فقط پردهٔ اول
```

## چرا این معماری

- **هیچ زمان‌بندی دستی وجود ندارد.** `tools/timeline.mjs` سکوت‌های ویس را با `silencedetect` پیدا می‌کند، جمله‌ها را به نسبت تعداد حرف روی زمان گفتار پخش می‌کند و همهٔ کات‌ها را می‌سازد. اگر ویس عوض شود، کل فیلم دوباره کات می‌خورد.
- **هر فریم مستقل است.** انیمیشن با CSS ساخته نمی‌شود؛ رندرگر `seek(frame)` را صدا می‌زند و همهٔ مفاصل از یک تابع بستهٔ زمانی می‌آیند. بنابراین رندر قابل توقف و ادامه است و هیچ فریمی شانسی نیست.
- **مفاصل واقعی‌اند.** `engine/rig.js` یک اسکلت با شانه/آرنج/لگن/زانو/گردن است؛ حرکت هر عضو فاز و دامنهٔ خودش را دارد تا جمعیت هم‌زمان و مکانیکی نرقصد.
