# ۱۵۱۸ — رقص استراسبورگ

ویدئوی عمودی ۹:۱۶ · فارسی · سبک «کتاب مصور» با شخصیت نقاشی‌شدهٔ کات‌اوت (اسپرایت پوز).

| مورد | مقدار |
| --- | --- |
| ابعاد | ۱۰۸۰×۱۹۲۰ (۹:۱۶) |
| نرخ فریم | ۳۰ fps |
| مدت | ۱۵۳٫۱ ثانیه (نریشن ۱۵۲ ثانیه + ۱٫۱ ثانیه نگه‌داشتن فریم آخر) |
| صحنه | ۲۰ صحنه — یک صحنه برای هر جملهٔ نریشن |
| زیرنویس | ۵۲ کیوی فارسی، داخل تصویر پخته‌شده + `subtitles/fa.srt` |
| صدا | `audio/mix.wav` — نریشن + درون (درون پایین، ضربان قلب هر ۱٫۴۲ ثانیه، روم‌تون) |
| بلندی صدا | ‎−۱۳٫۵ LUFS، پیک واقعی ‎−۰٫۸ dBTP |

## ساختار پوشه

```
vo/fa.wav              نریشن فارسی ضبطشده (۱۵۲s)
vo/fa.txt              متن خام نریشن فارسی
vo/en.wav              نریشن انگلیسی (۱۴۰٫۵s) — برای نسخهٔ دوم
vo/en.txt              متن انگلیسی (همان ۲۰ جمله)
content/script.js      متن بیست جمله (یک جمله = یک صحنه)
content/timeline.js    تولیدشده: زمان صحنه‌ها + کیوهای زیرنویس
content/scenes.js      پلیت، بازیگرها، جمعیت و حرکت دوربین هر صحنه
engine/partrig.js      ریگ کات‌اوت مفصل‌دار قهرمان (شانه/آرنج/گردن/لگن) + حرکت آهسته
engine/partrig-data.js تولید‌شده: پوزهای هر قطعه، محور مفصل‌ها، محل اتصال
engine/sprites.js      پوزر اسپرایت برای بازیگران فرعی (کات پوز + boil)
engine/sprites-data.js تولید‌شده: فهرست پوزها، لنگرِ پا و مقیاس بدن هر شخصیت
assets/sprites/*.png   پوزهای نقاشی‌شدهٔ جدا‌شده از پس‌زمینهٔ استودیویی
index.html             موتور صحنه (SVG + تایپوگرافی + پخش فریم‌به‌فریم)
assets/plates/sNN.jpg  بیست پس‌زمینهٔ نقاشی‌شده (بدون شخصیت، بدون متن)
audio/build.mjs        میکس نریشن + موسیقی
tools/timeline.mjs     ساخت تایم‌لاین از روی WAV نریشن
render.mjs             رندر فریم‌به‌فریم + انکود
```

## چطور دوباره ساخته می‌شود

```bash
node tools/timeline.mjs        # تایم‌لاین و SRT از روی ویس
node audio/build.mjs           # mix.wav
node render.mjs --stills 8     # بازبینی چند فریم
node render.mjs --fast         # فیلم کامل
node render.mjs --fast --from 0 --to 57   # فقط پردهٔ اول
python3 tools/build-sprites.py            # جدا‌کردن پوزهای نقاشی‌شده + ساخت sprites-data.js
```

## چرا این معماری

- **هیچ زمان‌بندی دستی وجود ندارد.** `tools/timeline.mjs` سکوت‌های ویس را با `silencedetect` پیدا می‌کند، جمله‌ها را به نسبت تعداد حرف روی زمان گفتار پخش می‌کند و همهٔ کات‌ها را می‌سازد. اگر ویس عوض شود، کل فیلم دوباره کات می‌خورد.
- **هر فریم مستقل است.** انیمیشن با CSS ساخته نمی‌شود؛ رندرگر `seek(frame)` را صدا می‌زند و همهٔ مفاصل از یک تابع بستهٔ زمانی می‌آیند. بنابراین رندر قابل توقف و ادامه است و هیچ فریمی شانسی نیست.
- **قهرمان ریگ مفصل‌دار دارد.** نقاشی به هفت قطعه جدا شکسته شد (سر، بالاتنه، پیش‌بند، دامن، بازو، ساعد+دست، ساق+کفش) و در SVG به‌صورت گروه‌های تودرتو سوار شد: لگن → بالاتنه → (شانه → آرنج، گردن). چرخش هر والد فرزندش را می‌برد، پس آرنج همیشه دنبال شانه می‌آید.
- **حرکت آهسته و با تأخیر.** نوسان بدن ~۰٫۴۲ هرتز، بازوها ~۰٫۲۹ هرتز، سر ~۰٫۲۱ هرتز؛ هر مفصل رانندهٔ خودش را ۰٫۱۶ ثانیه دیرتر می‌خواند تا اندام کشیده شود، نه پرش کند.
- **دوربین یکی برای همه.** یک تبدیل (پوش/پول + درِیفت دستی + رول ۰٫۲ درجه) هم‌زمان روی پلیت و روی گروه بازیگرها اعمال می‌شود؛ هیچ‌چیز روی پس‌زمینه نمی‌لغزد.
- **شخصیت نقاشی‌شده است، نه وکتور.** هر پوز یک نقاشی مستقل است که با همان مدل مرجع ساخته شده (همان زن، همان لباس، همان نور) و `tools/build-sprites.py` آن را از پس‌زمینهٔ خاکستری استودیو جدا می‌کند. اسکلت وکتوری قبلی حذف شد: صورت و چین پارچه‌اش به نقاشی نزدیک نمی‌شد.
- **همهٔ پوزها روی یک نقطه ثبت می‌شوند.** برای هر پوز، لنگرِ کفِ پا (`ax, ay`) اندازه‌گیری می‌شود و بدنهٔ هر شخصیت با `ref` خودش نرمال می‌شود؛ نتیجه: جابه‌جایی پوز اندازه یا جای شخصیت را تغییر نمی‌دهد.
- **کات، نه مورف.** پوزها با کات سخت روی ضرب عوض می‌شوند (انیمیشن محدود کلاسیک). کراس‌فیدِ دو سیلوئت این‌قدر متفاوت، دوبل‌اکسپوژر می‌شود؛ `CROSSFADE` در `engine/sprites.js` صفر است.
- **جانِ بین کات‌ها از جای دیگری می‌آید.** boil خط (۱۱ هرتز)، پرش روی ضرب، وزن‌اندازی و تنفس؛ و هر سه چرخهٔ رقص، یک ضرب با «تلوتلو» عوض می‌شود تا لوپ چهارپوزه مکانیکی نشود.
- **جمعیت سیلوئت است.** همان اسپرایت‌ها با `filter: brightness(.16)` در عمق صحنه؛ هم‌خوان با نقاشی، هم ارزان برای رندر.

## کارهای باقی‌مانده

- **نسخهٔ انگلیسی:** ویس و متنش آمادهست (`vo/en.wav` + `vo/en.txt`)؛ باید
  `timeline.en.js` / `en.srt` / میکس انگلیسی ساخته و همان تصویر با صدای
  انگلیسی رندر بشه. برای پروژههای جدید این کار با
  `npm run story:build -- <slug> --lang en` انجام میشه (موتور `engine/`).
