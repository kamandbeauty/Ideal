# painted-story — ورودی‌ها را اینجا بگذار

فقط دو چیز لازم است. هر دو را در فولدرهای مشخص‌شده بریز و بگو «آماده است».

---

## ۱. روایت صوتی → `inputs/voice/`

فایل ویس نریشن را اینجا بگذار. نام‌گذاری پیشنهادی:

```
inputs/voice/narration.wav     ← ترجیحاً WAV
```

(MP3 یا M4A هم قبول است. اگر چند تیکه است، `narration-01.wav`، `narration-02.wav` …)

**چیزی که خودم استخراج می‌کنم** — لازم نیست تو انجام بدهی:

| خروجی | روش |
| --- | --- |
| مدت دقیق و نرخ نمونه | `ffprobe` |
| سکوت‌ها و مرز جمله‌ها | `silencedetect` |
| تایم‌کد کلمه‌به‌کلمه | مدل ASR فارسی، روی همین فایل |
| متن نهایی برای زیرنویس | همان خروجی ASR، با بازبینی |

> اگر متن دقیق روایت را هم داری، در `inputs/voice/transcript.txt` بگذار.
> ASR خطا دارد و متن دستی کیفیت زیرنویس را بالا می‌برد. اگر نداری، مشکلی نیست.

---

## ۲. نمونه ویدیو → `inputs/reference/`

ویدیویی که می‌خواهی انیمیشن «این‌شکلی» باشد را اینجا بگذار:

```
inputs/reference/style-reference.mp4
```

از این فایل این چهار چیز را اندازه می‌گیرم (همان کاری که اسکیل‌های حرفه‌ای می‌کنند: با
`ffmpeg` و `scene detection`، نه با چشم):

| اندازه‌گیری | چرا |
| --- | --- |
| نرخ کات (کات در دقیقه) و میانهٔ طول شات | ریتم کلی |
| حرکت دوربین (پن/زوم/پوش‌این) | اینکه شات‌ها «زنده» به‌نظر بیایند |
| پالت رنگ و کنتراست | تا پلیت‌های جدید از پالت خارج نشوند |
| شدت و جای صدا | اینکه صدا زیر ویس گم نشود |

اگر فایل کوچک است (زیر ۵۰ مگابایت) می‌تواند در گیت بماند. اگر بزرگ‌تر است، فقط بگو
کجاست تا محلی نگهش دارم و کامیت نشود.

---

## ۳. اختیاری → `assets/brand/`

اگر این پروژه برای کماند است و باید لوگو یا پالت برند در کادر باشد، لوگو را
`assets/brand/logo.svg` (یا `.png` با پس‌زمینهٔ شفاف) بگذار.

---

## ساختار کامل

```
motion/painted-story/
├── inputs/
│   ├── voice/          ← ویس نریشن (تو)
│   └── reference/      ← نمونه ویدیو (تو)
├── assets/
│   ├── plates/         ← پلیت‌های صحنه (خروجی من)
│   ├── character/      ← دارایی‌های کاراکتر (خروجی من)
│   ├── fonts/          ← وزیرمتن و فونت تیتر
│   └── brand/          ← لوگو و پالت برند (تو، اختیاری)
├── audio/              ← mix.wav + words.json (خروجی من)
├── stills/             ← استیل‌های بازبینی (خروجی من)
├── exports/            ← ویدیوی نهایی (خروجی من)
└── README.md           ← همین فایل
```

## نکته‌ای که باید بدانی

سبکی که فرستادی **نقاشی‌شده** است، نه ریگ‌شده. پس انیمیشن از این جنس خواهد بود:

- پلیت‌های ثابت با **حرکت دوربین** (پن، زوم، پارالاکس)
- **تعویض کات** برای حس حرکت، نه حرکت پیوستهٔ کاراکتر
- **تعویض چهره** در کلوزآپ برای بازیگری

راه‌رفتن و حرکت پیوستهٔ اندام در این سبک نتیجهٔ قانع‌کننده نمی‌دهد — نه به‌خاطر
ابزار، بلکه به‌خاطر ماهیت خط و بافت نقاشی. اگر در نمونهٔ خودت کاراکتر واقعاً
حرکت پیوسته دارد، حتماً بگو؛ آن‌وقت مسیر دیگری (ریگ با اندام‌های جدا) را باز می‌کنیم.
