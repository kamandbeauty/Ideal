# بریف — درس پنجم «عوامل مؤثر در کشاورزی» (قابِ افقی)

فیلمِ آموزشیِ کلاسِ ششمِ یک‌دبستان یزدان؛ ساخته‌شده با همان موتورِ `motion/rowling-potter`
ولی برای اولین بار در **قابِ افقی ۱۶:۹**.

## قرارداد

| مورد | مقدار |
| --- | --- |
| قاب | ۱۹۲۰×۱۰۸۰ (۱۶:۹ افقی) |
| نرخ فریم | ۳۰ |
| مدت | ۹۶٫۳۲ ثانیه = ۲۸۹۰ فریم (ویس ۹۲٫۳۲ + ۴ ثانیه کارتِ پایان) |
| صدا | AAC-LC ۴۸k استریو ۱۹۲k · mix با loudnorm −۱۴ LUFS |
| ویدیو | H.264 High، CRF 24، +faststart |
| خروجی | `exports/yazdan-lesson5-1920x1080.mp4` |

## محتوا

- **۲۰ خطِ زیرنویس** — متنِ کاربر بدونِ تغییرِ کلمه؛ فقط شکستنِ جمله و حذفِ ایموجی.
- **۱۶ پلیت** — anime watercolour، همه ۱۳۷۶×۷۶۸ → ۲۵۶۰×۱۴۴۰.
- **هم‌ترازی** — whisper-base (faster-whisper، int8) + DP؛ ۱۹۴/۲۱۹ کلمه روی صدا قفل شد
  (`tools/word-timing.py`، کش: `/tmp/yazdan-asr-words.json`).
- **بدونِ لوگو** (به درخواستِ کاربر) و **با کارتِ پایانی**: «درس پنجم / عوامل مؤثر در کشاورزی /
  کلاس ششم — یک‌دبستان یزدان / تهیه: ساینا سلمان غانمی و فاطمه اسکندری».

## استایل

- زیرنویس: Vazirmatn 700، ۵۶px، lh 1.5، `left/right 170px`، `bottom 150px`، دور ۲٫۶px،
  کلمهٔ فعال `#ffd79a` + scale ۱٫۰۵، محو ۰٫۱۷s با blur ۵→۰.
- اسکریمِ موضعی زیرِ متن (بدونِ گریدِ سراسری).
- جو: warm / fog / leak / boil / grain ۶٪ / dust ۱۸ ذره / flash ۰٫۰۹.
- کارتِ پایانی: پردهٔ رادیالِ تیره (مثلِ فیلمِ رولینگ) + تیتر ۸۲px + خطِ طلایی + اعتبارها؛
  شروع ۹۲٫۵s، پایان با محوشدگیِ ۰٫۹s.
- محوشدگیِ گذار: ۰٫۵s + افتِ روشناییِ ۰٫۱۸.

## دوربین

همان قانونِ کانال: مسیرِ پیوسته در طولِ **کلِ صحنه** (`legs = dur/5.2`) با زومِ نفس‌کشنده،
چرخشِ آرام، رانشِ یک‌طرفه، لرزشِ نرم و تنفس؛ هیچ ریستی در مرزِ زیرنویس.

## دستورِ ساخت

```bash
npm install
python3 tools/word-timing.py         # timeline.js + words.js
node audio/build.mjs                 # mix.wav
python3 tools/upscale-plates.py a01 … a16
node render.mjs --stills 8           # بازبینی
node render.mjs                      # خروجیِ کامل
```
