## ۱. اصول قطعی (House rules)

| موضوع | قانون |
| --- | --- |
| کادر | عمودی ۹:۱۶، ۱۰۸۰×۱۹۲۰، ۳۰ fps |
| گرامر پلان | **یک تصویر نقاشیشده برای هر جملهٔ نریشن**، کات سخت، ۱٫۵–۳ ثانیه. نه فید، نه کراسفید، نه زوماوت پایانی |
| حرکت | فقط دوربین آرام روی پلیت (پوش/پول/پن/تیلت + لرزش دست + نفس)، نور شمع، مِه، دانه، وینیت. **حرکت اندام image-to-video ممنوع** |
| تصویر | نقاشی دیجیتال دوبعدی، خط دور مشکی تمیز، سلشید تخت، بافت کاغذ؛ حس کتاب مصور/چاپ سنگی قرونوسطایی |
| پالت | اکر، زیتونی، قهوهای گردو، آسمان آبی کمرو، نور شمع کهربایی؛ سایهها سرد آبیخاکستری. **هیچ رنگ نئونی/اشباعشده** |
| شخصیتها | چهرههای ساده و ثابت، چشمهای درشت، لباس دورهای؛ تداوم کاراکتر بین پلانها |
| تایپوگرافی | **فقط زیرنویس.** فارسی سفید بولد وزیرمتن، دورخط تیره + سایه، پایین کادر، وسطچین، حداکثر دو خط. کلمهٔ درحالگفتن کهربایی + خط کاراوکه. بدون لوگو/شماره/HUD |
| صدا | نریشن (ضبط واقعی کاربر، نه TTS) + درون ۵۵Hz + ضربان قلب ۱٫۴۲s + رومتون، sidechain ducking، −14 LUFS |
| زمانبندی | از `silencedetect` روی ویس؛ هیچ کات دستی. هر فریم `seek(frame)` و قطعی |
| زبان | یک تصویر، دو خروجی جدا: MP4 فارسی + MP4 انگلیسی، هر کدوم SRT خودش |

پیادهسازی این قوانین تو `stage.html` و `engine/*.mjs` قفل شده؛ قبل از
تغییرش [`engine/README.md`](../engine/README.md) رو بخون.

## ۲. تحلیل نمونهٔ مرجع

منبع: `reference/InShot_20261102_212035308.mp4` (۲ نوامبر ۲۰۲۶).

| مورد | مقدار |
| --- | --- |
| ابعاد | ۶۷۲×۱۲۰۰ (۹:۱۶)، DAR 9:16 |
| نرخ فریم | ۳۰٫۰۶ fps |
| مدت | ۳۵٫۵۰ s |
| ویدئو | H.264 High ~4.1 Mbit/s، yuv420p |
| صدا | فقط موسیقی/افکت (نریشن جدا میاد) |

۱. **تصویرسازی، نه عکاسی.** خط دور مشکی، سایهزنی مسطح، کمی بافت کاغذ.
۲. **پالت گرم و خاکی.** شبها ایندیگوی تیره، نور شمع کهربایی.
۳. **شخصیتها ثابت و کارتونی.** حالت اغراقشده (ترس/حیرت)، تکرار شخصیت
   اصلی برای حفظ تداوم.
۴. **یک تصویر برای هر جمله.** کات سخت روی هر تغییر زیرنویس، ≈۱٫۵–۳ ثانیه.
۵. **حرکت داخل پلان.** پوش آهسته + حرکت بدن (توی نمونه image-to-video)،
   جمعیت کمی موج میخوره.
۶. **تایپوگرافی = فقط زیرنویس.** فارسی بولد سفید، دورخط تیره، سایهٔ نرم،
   اعداد فارسی، حداکثر دو خط.
7. **بدون تیتر/لوگو/شماره/HUD** روی تصویر.

### نریشن پروژهٔ مرجع

`motion/dance-1518/vo/fa.wav` — ۱۵۲٫۰ s · mono 24 kHz PCM.
`silencedetect` (`‑32 dB`, `≥0.28s`) سیودو سکوت ⇒ **۳۳ بلوک گفتار** پیدا کرد؛
`motion/dance-1518/vo/fa.txt` متن خامه و چند خط آخرش بریده — متن نهایی
تو `content/script.js` از روی صدا بازسازی شده.

نسخهٔ انگلیسی همان فیلم: `motion/dance-1518/vo/en.wav` (۱۴۰٫۵s) +
`vo/en.txt` (متن انگلیسی، همان ۲۰ جمله). هنوز رندر نشده.

## ۳. چه چیزی توی این محیط شدنیه / نیست

| شدنی ✔ | نشدنی ✘ |
| --- | --- |
| تصاویر ایستای نقاشیشده + کات سخت روی هر جمله | انیمیشن واقعی اندام (image-to-video) — مدل تولید ویدئو اینجا نیست |
| حرکت دوربین، لرزش کاغذ، نور شمع، دانه، وینیت | اگر کلیپ متحرک لازمه باید بیرون ساخته و آپلود بشه |
| زیرنویس سوختهٔ فارسی/انگلیسی با فونت لوکال | |
| ۱۰۸۰×۱۹۲۰ · ۳۰fps · H.264 + AAC | |

**راهحل انتخابشده:** موشنکامیک — تصویر ایستا + دوربین آرام + کات سریع +
زیرنویس کینتیک. «جانِ» بین کاتها از boil خط، پرش روی ضرب، وزناندازی،
تنفس و ریگ کاتاوت (`motion/style-v3-poc/`، و `motion/dance-1518/engine/`
برای نسخهٔ مفصلدار) میاد، نه از مورف بین دو سیلوئت.
