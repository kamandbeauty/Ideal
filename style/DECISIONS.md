## معماری الان

```
style/      ← سبک و مرجعها
engine/     ← موتور مشترک (همهٔ پروژهها از این استفاده میکنن)
projects/   ← هر فیلم = دادهها + ویس + خروجی
motion/dance-1518/  ← پروژهٔ تحویلشدهٔ مرجع، مستقل و دستنخورده
motion/odd-file/    ← برند جداگانهٔ انگلیسی (بایگانی، دستنخورده میمونه)
```

> نکته: `motion/dance-1518/` عمداً موتور خودش رو نگه داشت تا آرشیو قابل
> replay باشه؛ پروژههای **جدید** حتماً از `engine/` استفاده میکنن.
