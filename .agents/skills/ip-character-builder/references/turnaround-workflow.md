# 三视图构建工作流

## 输入要求

优先使用：

- 一至多张清晰、无遮挡、能辨认发型、脸型、体型和主要服装的人物照片。
- 用户拥有使用权的角色插画参考。
- 已经完成的正面、侧面、背面三视图。

照片只用于当次视觉参考，不进入最终包。输入不足以判断固定特征时先说明缺口，不擅自发明身份特征。

## 总结人物特征

将观察和用户偏好分开表达，围绕以下可执行视觉维度总结：

1. 发型轮廓、长度、分缝和发色。
2. 脸型、眉眼、鼻、嘴、眼镜等高识别特征。
3. 体型、肩宽和头身比例。
4. 角色定位、年龄感、气质和常用表情。
5. 服装版型、层次、稳定色和材质语言。
6. 固定配件、佩戴位置和鞋型。
7. 允许变化与明确禁止的漂移。

不要记录敏感身份、联系方式或与造型无关的背景信息。

## 设计迭代

- 一次优先解决一个主要问题，例如表情、外套版型或局部配色。
- 将用户确认的选择升级为固定规则；未确认的生成细节保持可变。
- 每次修改后检查正、侧、背三个角度是否同步。
- 不以美化为由改变年龄、体型、脸型或身份。
- 用户提供风格参考时提取线条、用色、明暗和比例语言，不复制参考角色身份。

## 统一画面要求

生成一张包含同一角色三个全身视图的专业三视图：

- 依次展示正面、标准侧面和背面。
- 三个视图年龄、脸型、发型、肤色、体型、头身比、服装和配件一致。
- 使用自然直立的中性姿势，手臂不遮挡身体主要结构。
- 使用相同画面尺度、身体高度和地面线；全身完整，不裁切。
- 侧面清楚表现鼻、下巴、后脑、服装侧面和鞋型。
- 背面清楚表现发型后部、服装背部、配件后部和鞋跟。
- 固定配件在各角度保持同一侧、材质和形状。
- 使用纯白或极浅无干扰背景，不加标题、道具、场景或装饰边框。
- 视觉风格遵循用户参考；没有参考时使用结构清晰、便于复用的 2D 角色设定图。

## 可执行生成 brief

替换方括号内容：

> 创建一张专业角色三视图，横版画布，纯白背景。依次展示同一角色的正面、标准侧面和背面，全身完整、不裁切、相同高度、相同地面线、自然直立中性姿势。角色定位为[定位和气质]；固定身份特征为[发型、脸型、五官、肤色、体型、头身比例]；穿[服装结构与稳定配色]；佩戴[固定配件及准确位置]。三个角度必须保持同一身份、身体比例、服装结构、配件侧别和鞋型。使用[用户确认的视觉风格]。不加入场景、道具、标题、阴影人物或额外角色。禁止[禁止漂移]。输入照片只作为身份参考，不把照片或路径放入输出。

若工具支持参考图，直接传入相关照片、风格参考或已有三视图，不只依赖文字复述。

## 质量检查与确认

- [ ] 只有同一角色的三个角度，没有额外人物。
- [ ] 正面、侧面、背面齐全，方向清楚。
- [ ] 身高、头身比、肩宽和四肢长度一致。
- [ ] 发型、脸部结构、眼镜或其他身份锚点稳定。
- [ ] 服装版型、主色、鞋型与配件位置一致。
- [ ] 没有无关道具、文字、场景或裁切。
- [ ] 风格参考只影响画法，没有替换人物身份。

请用户确认角色身份和固定规则。用户要求修改时保留原结果，使用新文件名或新版本 ID，除非用户明确授权覆盖。
