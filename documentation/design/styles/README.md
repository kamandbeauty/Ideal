# Building style studies

Four directions for the look of the businesses in Roadstop Tycoon. They are
concept renders, not in-engine captures, and they exist so the direction can be
chosen before any modelling or material work starts.

| File | Direction | What it means in the build |
| --- | --- | --- |
| `style-a-pastel.jpg` | Soft pastel | the current palette, pushed lighter and friendlier: mint, coral, cream, teal roofs, big soft shapes |
| `style-b-retro.jpg` | Retro 50s | Route 66: red-and-cream diner, chrome trim, neon motel sign, badge on the asphalt, sunset light |
| `style-c-geometric.jpg` | Clean geometric | flat shading, one accent colour per building, almost no props, strongest readability on a phone |
| `style-d-warm-detailed.jpg` | Warm detailed | ochre sand, wooden porch, hanging lamps, terrace with parasols, more props per plot |
| `styles-overview.jpg` | all four side by side | the sheet used for the choice |

The vertical slice is built from the Kenney city-builder kit plus primitive
props, so a choice changes the palette, the materials, the roof/sign shapes and
the prop set - not the whole model library.

**Chosen: B - Retro 50s (pure, no mix).** Implemented in 0.9.0: recoloured
palette atlas for the kit models, chrome skirting, candy-striped awnings, roof
neon, googie pylon signs, double yellow centre line and a retro vehicle palette.
