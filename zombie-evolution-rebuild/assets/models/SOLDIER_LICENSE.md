# Soldier model

`soldier-quaternius.glb` is `soldier_male_mid.glb` from
[DaSarBe/army_diary](https://github.com/DaSarBe/army_diary/blob/main/island/assets/quaternius/soldier_male_mid.glb),
a decimated Blender conversion of Quaternius's Ultimate Animated Character
Pack. The upstream [source notes](https://github.com/DaSarBe/army_diary/blob/main/island/assets/SOURCES.md)
identify it as CC0 1.0. The original [pack listing](https://opengameart.org/content/animated-characters-pack)
also identifies the pack as CC0. Author: Quaternius. The conversion contains
Idle, Walk, Walk_Carry, Shoot_OneHanded, Punch, RecieveHit and Defeat clips;
there is no separately authored run clip.

`rifle-quaternius.glb` is `rifle_t91.glb` from the same conversion repository,
whose source notes identify it as `AssaultRifle_1` from the Quaternius Ultimate
Guns Pack, CC0 1.0. [Original pack listing](https://opengameart.org/content/low-poly-guns-pack).
