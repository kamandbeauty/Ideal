# Bamen soldier — staged character evaluation

`soldier-bamen-reference.glb` is the unchanged `soldier.glb` from
[Hungden2k13/Deadlock commit 7de622dd55cd8872715e56f2b7c19e86c841eede](https://github.com/Hungden2k13/Deadlock/tree/7de622dd55cd8872715e56f2b7c19e86c841eede/public/assets/models/characters).
The source project identifies the mesh and rig as **FREE [Military Soldier] RIGGED**
by BAMEN, [source](https://sketchfab.com/3d-models/free-military-soldier-rigged-e9c56308a67d4a3db62e914fafa4d198),
licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The source
project states it modified the model and retargeted Quaternius Universal
Animation Library 1 and 2 clips (CC0); some `mocap_*` clips come from the
[100STYLE dataset](https://zenodo.org/records/8127870) by Ian Mason, Sebastian
Starke and Taku Komura, CC BY 4.0, extracted and retargeted by that project.
See [source credits](https://github.com/Hungden2k13/Deadlock/blob/7de622dd55cd8872715e56f2b7c19e86c841eede/README.md#credits--licences).
No changes to the GLB have been made in this project.

This asset is staged for inspection and is not currently used for gameplay.
Proper two-handed rifle placement is not provided by the GLB itself; the
source game implements support-hand IK. Visual quality and compatibility must
be tested before replacing the hero and squad. The existing user-supplied hero
remains unchanged.
