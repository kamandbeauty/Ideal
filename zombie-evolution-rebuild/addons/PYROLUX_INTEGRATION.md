# PYROLUX Lite integration

The user supplied `pyrolux_lite_store_v1.0.3.zip` and stated that they have full permission to use its contents, including when asked to use Pyrolux. The unmodified `pyrolux_fx` addon files and their original license and credits are retained here; generated Godot import metadata and the demo are not copied. The included license has its own redistribution restrictions and this record does not supersede those terms.

The game instantiates the included grenade explosion preset as a small, low-quality, light-free air burst when the stage brute is defeated. It is cosmetic: no extra damage, sound, scoring, weapon cadence or gameplay collision changes. It is not spawned on every bullet, and frees itself after completion. The effect is only an addition to the existing death animation and knockback. Test and review on real Android hardware is still necessary to determine actual appearance and performance.
