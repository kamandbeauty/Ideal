# نصب و تست روی سایت واقعی

## پیش‌نیازها

| مورد | حداقل | چرا |
|---|---|---|
| WordPress | 6.0 | Block API و REST |
| PHP | **8.1** | کد از `match`، `enum` و typed properties استفاده می‌کند |
| WooCommerce | 8.0 | فقط برای سبد خرید و سفارش؛ بدون آن طراح کار می‌کند ولی «افزودن به سبد» نمایش داده نمی‌شود |
| MySQL / MariaDB | 5.7 / 10.3 | جدول‌ها `utf8mb4` هستند |
| افزونه GD در PHP | لازم | تولید فایل‌های چاپ |
| افزونه ZipArchive | لازم | خروجی ZIP سفارش |
| مرورگر | WebGL | پیش‌نمایش سه‌بعدی |

> **مهم:** اگر هاست شما PHP 8.0 یا پایین‌تر دارد، افزونه فعال **نمی‌شود**. اول نسخهٔ PHP را در cPanel/پنل هاست بالا ببرید.

## ۱. ساخت فایل نصب

```bash
./tools/build-zip.sh
# -> dist/custom-product-designer-1.2.0.zip
```

اسکریپت پوشهٔ `tests/` را حذف می‌کند و بررسی می‌کند مدل‌های سه‌بعدی، فایل ترجمه و
`uninstall.php` واقعاً داخل بسته باشند. اگر چیزی جا بیفتد، با خطا متوقف می‌شود.

## ۲. نصب

پیشخوان وردپرس → **افزونه‌ها → افزودن → بارگذاری افزونه** → انتخاب فایل ZIP → **اکنون نصب کن** → **فعال کردن**.

اگر خطای «حجم فایل بیش از حد مجاز» گرفتید (بسته ۲.۵ مگابایت است)، یا `upload_max_filesize`
را بالا ببرید یا پوشهٔ داخل ZIP را با FTP در `wp-content/plugins/` بگذارید.

## ۳. چه اتفاقی موقع فعال‌سازی می‌افتد

فعال‌سازی به‌صورت خودکار:

- ۱۳ جدول با پیشوند `wp_td_` می‌سازد،
- دو مدل نمونه (تی‌شرت و توت‌بگ) با رنگ، سایز و ناحیهٔ چاپ اضافه می‌کند،
- ۱۷ طرح نمونه وارد می‌کند،
- یک کرون روزانه برای پاک‌سازی طرح‌های مهمان ثبت می‌کند.

یعنی **بلافاصله قابل استفاده است** و نیازی به پیکربندی اولیه ندارید.

## ۴. ساخت صفحهٔ طراح

یک برگهٔ جدید بسازید و این کد کوتاه را بگذارید:

```
[tshirt_designer]
```

برگه را منتشر کنید و ببینید. مدل سه‌بعدی باید بارگذاری شود.

## ۵. مسیر تست پیشنهادی

1. یک مدل انتخاب کنید (تی‌شرت).
2. رنگ و سایز را عوض کنید — مدل باید بلافاصله رنگ عوض کند.
3. یک طرح از گالری اضافه کنید و جابه‌جا/بزرگش کنید.
4. متن فارسی اضافه کنید و فونت را عوض کنید.
5. **افزودن به سبد** را بزنید → **پیش‌نمایش محصول** باز می‌شود (قابلیت فاز ۳.۲).
6. نماها را عوض کنید (جلو/پشت/آستین‌ها)، زوم کنید، **تأیید طرح و ادامه** را بزنید.
7. سبد خرید ووکامرس باید طرح را با قیمت درست نشان دهد.
8. سفارش را نهایی کنید و پرداخت را به «تکمیل‌شده» تغییر دهید.
9. پیشخوان → **Product Designer → Production** — باید یک کار تولید ساخته شده باشد.
10. وارد کار تولید شوید: فایل‌های PNG هر ناحیه و دکمهٔ دانلود ZIP را ببینید.

## ۶. منوی مدیریت

**Product Designer** در نوار کناری، با زیرمنوهای:
Models · Product Types · Colors · Sizes · Print Areas · Design Assets · Pricing · Designs · **Production** · Settings

## ۷. اگر مشکلی پیش آمد

فایل `wp-config.php` را موقتاً این‌طور کنید تا خطاها را ببینید:

```php
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
define( 'WP_DEBUG_DISPLAY', false );
```

خطاها در `wp-content/debug.log` ثبت می‌شوند.

| علامت | علت محتمل |
|---|---|
| افزونه فعال نمی‌شود | PHP زیر 8.1 |
| صفحهٔ طراح سفید است | WebGL در مرورگر غیرفعال؛ کنسول مرورگر را ببینید |
| مدل سه‌بعدی بارگذاری نمی‌شود | مسدود بودن `.glb` توسط سرور — نوع MIME `model/gltf-binary` را اضافه کنید |
| «افزودن به سبد» نیست | WooCommerce فعال نیست |
| فایل چاپ ساخته نمی‌شود | افزونهٔ GD نصب نیست |
| ZIP کار نمی‌کند | افزونهٔ ZipArchive نصب نیست |

## ۸. حذف کامل

در **Settings** گزینهٔ حذف داده‌ها را روشن کنید، سپس افزونه را **حذف** (نه فقط غیرفعال) کنید.
با آن گزینه، هر ۱۳ جدول و همهٔ فایل‌های تولیدشده پاک می‌شوند. اگر خاموش باشد، هیچ داده‌ای
حذف نمی‌شود.

## ⚠️ هشدار مهم

روی **سایت اصلی و زنده نصب نکنید**. دلیل فنی مشخصی دارد: پایگاه‌داده تا امروز فقط روی
SQLite اجرا شده و روی MySQL واقعی **اجرا نشده است** (جزئیات در
`docs/PHASE-3.1-REPORT.md`). گرامر SQL با پارسر واقعی MySQL 8 بررسی و تأیید شده، ولی این
جای اجرای واقعی را نمی‌گیرد.

پیشنهاد: اول روی یک سایت آزمایشی یا staging نصب کنید، و **قبل از هر نصبی از پایگاه‌داده
پشتیبان بگیرید**.
