## Current base build

Ruby Run 3D is an offline stage-based game. The repository's base build creates no account, includes no advertising or analytics SDK, transmits no gameplay information, and does not request access to location, contacts, phone, SMS, camera, microphone, photos, or personal files.

## Local information

Stage progress, coins, upgrades, unlocked/selected skins, daily-reward timestamps, quality, music, sound, and vibration preferences are stored in Android app-private storage. This data is used only to provide the game. Settings provides a confirmed local-data reset. Uninstalling normally removes app-private data, subject to platform backup settings.

The daily reward reads UTC device time and stores a local timestamp to detect obvious clock rollback. It is not used to infer location and is not transmitted.

## Advertising and analytics

No ad or analytics provider is included or enabled in the base build. Provider boundaries are intentionally unavailable without reviewed configuration. If a future build adds a provider, Studio Javid must update this policy, consent behavior where required, the SDK inventory, Android manifest review, and store Data Safety declaration before distribution.
